# Contributing

Wording examples, strategy improvements, and source corrections are welcome. Keep the scientific meaning intact and focus on LLM review preferences.

For a strategy change, include:

- A before/after example.
- A short explanation of the change and why it helps address LLM wording preferences.
- A relevant source link when drawing on research.

Label fictional examples. If sharing measured scores, include the reviewer model, scoring setup, and how the examples were selected. Ordinary documentation and strategy contributions do not require a benchmark run.

Keep the skill self-contained inside `skills/game-the-llm-reviewer/`, with no required reviewer API. Update the README when user-facing behavior changes. Keep private manuscripts and credentials out of pull requests, and share only text you have permission to redistribute.

Small fixes can be small pull requests.
